# Circa perpetual calendar transfer

Source: project chat `01a192f6-d620-71f9-a0ac-bfcf8bb2507c`. The original editable build and final revisions were recovered from the chat's command history, rather than redrawn from the appearance concept. This preserves the stacked wheel spokes, all raised labels, 168 mm date ring, 176 mm spine, 8 mm axle, 8.6 mm bores, two 0.6 mm spacers, cap, 9 × 9 mm pointer window and original rectangular base plus the three replacement stands (oval, twin-foot and stepped).

The site entry is Reading → Circa perpetual calendar, with a direct homepage link. Dimensions and original four colours are fixed. Palette and generic clearance controls are disabled for this item. All four stands use the original socket and are interchangeable. Only the selected stand is exported. There are nine physical parts; colour volumes are grouped in the 3MF as multi-part objects.

`src/calendar/circa-geometry.json` contains the recovered generator's unscaled triangulated geometry. `scripts/calendar/original-build.py` and `original-stands.py` preserve its editable Blender source. The small `export-site.py` bridge regenerates the geometry in the original `/workspace/circa/printable` working layout. Blender's default font is retained, matching the original printable design. No image-generated artwork is substituted for print geometry.

`src/calendar-product.js` unions same-colour volumes and removes body/letter overlap, preserving the exact outside shape. Geometry regression tests compare each exported physical part against the union of its original source meshes for every stand and both printers. The spine rotates 45° in the XY printing plane; it is not shortened or resized. Its printing footprint is approximately 134.35 × 134.35 mm, within the normal mini design allowance. The assembled preview applies the inverse print rotation before placing it in the original assembly.

Print settings remain the site's normal 8% gyroid, 2 walls and 3/3 skins with 0.2 mm layers, 0.4 mm nozzle and PLA. Original pointer and cap recesses retain automatic normal supports. The prime tower starts off so the 168 mm ring fits the A1 mini; filament-change nozzle purging remains. The guide explains these choices. Both printer profiles remain selectable, defaulting to A1 mini. AMS export now supports a declared filament count rather than assuming two slots; existing two-colour exports retain their previous settings.

Validation: exact source geometry preservation, closed connected physical groups, all dates, bed dimensions, four-slot AMS assignments, prepared plates, profile consistency and unmutated shared presets. Browser checks exercise all four stands, both printer downloads, disabled fixed-design controls, STL/guide, mobile overflow and reset. Native slicer checks and isolated Bambu 2.8.2.61 Open/Save verify the actual project files.
