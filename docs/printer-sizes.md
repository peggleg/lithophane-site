# Shared printer sizes

Every generator starts with **A1 mini**. Its physical bed is 180 × 180 × 180 mm, with the existing 170 mm per-part design allowance. The optional **256 × 256 × 256 mm** selection permits finished parts up to that size and currently exports a Bambu Lab A1 / 0.4 mm / Generic PLA project. The model name is explicit in the picker and guides. The choice is per page/session, not stored as a new default. Reset returns to A1 mini. Choosing another product on the same page preserves the choice.

`src/printer-settings.js` owns printer identities, dimensions and measured-part checks. `src/printer-picker.js` mounts the same control across lithophanes/lanterns, fans, keyrings, nameplates, clickers, desk, kitchen, bathroom and coasters. Width/depth/height limits update where relevant. Mechanical bounds still apply: soap and pill-box heights, switch sockets, hinges, and fixed postcard/LED lantern geometry do not stretch merely because the selected bed is larger. Coaster inputs reserve room for holders; final generated holders are checked again. Fan length reserves the 6 mm pivot end. Larger roll-shaft sections may use up to 256 mm, while the A1 mini setting retains the original 150 mm section limit.

Every part is checked in its supplied printing orientation. Assembled fans, cupboards, plant displays and batches may be larger than the printer and require multiple plates. Long letter charms wrap into joined rows to fit their selected bed, without altering cap or switch fit. Switching a large design back to A1 mini invalidates it and disables exports until corrected; dimensions are never silently reduced. Memory/mesh-quality budgets are unchanged.

3MF exports carry the selected machine, bed, filament and process parent, including every photo/lantern frame and panel project. The 256 option uses the resolved official A1 profile in `src/profiles/a1-pla.json`; A1 mini's original profile is unchanged. `different_settings_to_system` preserves deliberate process keys through Bambu's desktop preset loader. STL ZIPs include `PRINTER-SETTINGS.json` alongside the unchanged process-only `PRINT-SETTINGS.json`, named parts and their guide. Standalone STL has no printer settings; choose the matching printer in the slicer.

Print policy remains 8% gyroid, two wall loops, zero minimum skin thickness, and the existing 2/2 text, 4/4 photo, 5/5 coaster and 3/3 other skin policies. Both profiles keep 0.2 mm layers. Allow space for brim, supports and slicer keep-out areas, especially when using the full 256 mm extent.

Validation covers both sizes, default/reset, unsupported choices, large/over-limit models, symbol placement, long-charm connectivity, measured final bounds, guides and sidecars. `scripts/check-printer-browser.mjs` exercises actual exports on all nine pages, both lantern profile types, the custom-photo save dialog, mobile layouts and stale-export invalidation. `scripts/check-printer-import.mjs` imports all skin-policy families on both machines in official Bambu Studio 2.8.2.61; `scripts/check-bambu-desktop.py` additionally verifies machine, bed and filament through desktop Open Project / Save Project. `scripts/check-printer-slices.mjs` slices an exactly 256 mm-wide panel and a 220 mm cupboard case on the selected A1 bed. Digital size and slicer checks do not prove physical fit or strength for enlarged designs.
